# Week1Task5 — сравнение ответов трёх LLM

Полностью клиентское веб-приложение (HTML/CSS/JavaScript, без серверной части),
которое отправляет один и тот же текстовый запрос в три разные модели и выводит
метрики: время ответа, количество токенов и рассчитанную стоимость.

## Модели

| Провайдер | Модель | Эндпоинт |
|-----------|--------|----------|
| DeepSeek  | `deepseek-v4-flash` | `https://api.deepseek.com/chat/completions` |
| DeepSeek  | `deepseek-v4-pro`   | `https://api.deepseek.com/chat/completions` |
| Groq      | `allam-2-7b` | `https://api.groq.com/openai/v1/chat/completions` |

## Как запустить

1. Откройте `index.html` в браузере или разверните папку на GitHub Pages.
2. Введите общий текст запроса.
3. Введите API-ключи для нужных моделей (DeepSeek, DeepSeek, Groq).
4. Нажмите «Отправить».

Ключи используются **только в рамках текущей вкладки** и нигде не сохраняются
(нет localStorage/cookies/других хранилищ). Запросы к API выполняются напрямую
из браузера — оба API поддерживают CORS, поэтому прокси не требуется.

## Тарифы (USD за 1 млн токенов)

Тарифы захардкожены в `script.js` (константа `MODELS`).

- **DeepSeek V4 Flash / V4 Pro** — актуальные цены из официальной документации
  (`https://api-docs.deepseek.com/quick_start/pricing/`). Учитываются пиковые
  и внепиковые часы (внепиковые в 2 раза дешевле), а также разделение входных
  токенов на кэш-попадание и кэш-промах.
- **Groq `allam-2-7b`** — бесплатная модель (в списке моделей Groq API у неё нет
  поля `pricing`), поэтому стоимость $0.

Формула стоимости:
`(input_tokens * price_input + output_tokens * price_output) / 1_000_000`.

## Структура

- `index.html` — разметка.
- `styles.css` — стили.
- `script.js` — логика (конфигурация моделей, запросы, расчёт метрик).
